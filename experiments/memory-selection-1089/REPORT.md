## 工作经验、Skill、MemHub

Hy coding/working能从带工具调用的轨迹提炼事实和经验，返回文件、验证结果、适用项目及关联事实。本轮PHP记住事务+唯一幂等键、废弃内存锁、20项通过；Node记住outbox和12项通过。working记住发布完成及回滚地址。**这不是可执行Skill的安装、版本发布或审核系统**；该SDK没有本任务需要的原生Skill发布工作流。

Core code对同一轨迹的三个问答通过。另在独立库调用真正的 `/v3/skill/extract`：入队成功，worker约19.8秒后 `outcome=ok,candidates=0`，两次模型调用，列表仍空。它只证明本样本完成审查并未产生技能，不证明成功生成/发布。生成schema里出现的 `/v3/skill/import` 在这个固定运行版本实际返回404，不能依据文档表格算支持。

手工管理补测在**本轮新建的本地测试实例**中创建owner/team/agent和两条合成Skill，未使用任何既有管理员凭据；这些本机初始化凭据没有交给模型。创建结果直接为 `status=active,version=1`，本人可回读正文，其他范围按IDcode40401。这里名为public的team只是合成范围，不会自动跨team共享。当前运行版的active/archived管理不等于人类candidate→approved发布；需要接入层审核。未安装或执行Skill脚本。
